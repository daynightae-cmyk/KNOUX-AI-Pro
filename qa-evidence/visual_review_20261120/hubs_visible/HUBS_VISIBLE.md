# الأربع مراكز الإضافية بقت قابلة للوصول باللمس + تصحيح نصوص

## المشكلة (اكتشفها المالك على الجهاز)
التصميم الملكي والوضع النهاري كانوا مثبتين على الجهاز، لكن الأربع صفحات
الجديدة (developer-info / google-services / advanced-security /
backup-restore) كان ليها مسارات مسجلة فقط — مفيش أي عنصر UI بيوصلها.
كانت بتتفتح حصريًا عبر خطاف debug (--es route)، فالمستخدم العادي عمره
ما كان هيلاقيها. قصور حقيقي في قابلية الوصول، مش في التثبيت.
