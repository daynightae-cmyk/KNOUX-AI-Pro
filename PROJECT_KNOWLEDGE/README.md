## الاستخدام الصحيح

المشروع الحالي هو `K:\KNOUX-AI-Pro` و`master`. مشروع `D:\KNOUX-AI` مستقل و`main`، ولا تُنقل منه حالة Build/Test أو كود بلا مهمة محددة. وثائق AndCode/Phone القديمة مفيدة لفهم القرارات والأصول، لكنها ليست مكان تنفيذ حاليًا.

المكتبة **لا تتدخل في تصميم أو كود التطبيق**؛ أي وكيل حر يبتكر في المهمة المطلوبة، مع الرجوع إلى المرجع المعتمد وكود المشروع الفعلي. الملفات القديمة لا تُلغي قرارات المالك الأحدث. افحص Git الحالي والاختبارات والتشغيل قبل إعلان نجاح.

## ما لم يُنسخ

لا تحتوي المكتبة على أرشيفات ZIP/TAR أو APK أو build cache أو قاعدة OpenCode الأصلية أو Google OAuth Client Secrets أو Supabase Service Role/Management Token. ملفات المصداقية الأصلية محفوظة في مواضعها؛ الموجود هنا وثائق وصور محددة وفهرس. مسارات المصادر التفصيلية في `90_INDEX/*.local.csv` محلية ومتجاهلة من Git لتفادي نشر معلومات الجهاز.

**تاريخ إنشاء أول نسخة:** 2026-11-15. تحديث المكتبة لا يساوي تحديث كود التطبيق، ولا يعني أن كل مرفقات الهاتف القديم متاحة على الكمبيوتر.
